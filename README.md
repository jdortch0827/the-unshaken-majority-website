# The Unshaken Majority Website

Static, mobile-first website for The Unshaken Majority.

## Included

- Home page
- Same Standard Test investigation archive
- Evidence and correction standards
- Case-submission page
- Contact and official social links
- Mobile navigation
- Vercel configuration
- SEO metadata, sitemap, robots file, favicon, and social preview image

## Deploy with Vercel

1. Upload every file and the `assets` folder to the root of the private GitHub repository.
2. In Vercel, choose **Add New → Project**.
3. Import the GitHub repository.
4. Keep **Framework Preset** as `Other` if Vercel does not automatically detect a static site.
5. Leave build and output settings blank.
6. Deploy.
7. In the Vercel project, add `theunshakenmajority.com` and `www.theunshakenmajority.com` under **Settings → Domains**.
8. Use the DNS values Vercel provides in Porkbun. Do not guess them because Vercel may issue project-specific instructions.

## Submission form

The first release uses the visitor's email application. It does not store submissions on the website. The form builds an email to `theunshakenmajority@gmail.com` and instructs the sender to attach evidence.

## Content rule

Do not publish allegations as established fact before the supporting evidence, comparison, and response have been reviewed.
