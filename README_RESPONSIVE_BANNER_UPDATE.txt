THE UNSHAKEN MAJORITY — RESPONSIVE BANNER UPDATE

PURPOSE
This targeted update gives the website separate desktop, tablet, portrait-phone,
and landscape-phone banner behavior. It prevents the original wide banner from
being unpredictably cropped by background-size: cover.

FILES INCLUDED
- styles.css
- assets/banner-dark-tablet.png
- assets/banner-dark-mobile.png

GITHUB UPLOAD
1. Open the existing the-unshaken-majority-website repository.
2. Choose Add file > Upload files.
3. Drag everything INSIDE this extracted folder into the repository.
4. Allow styles.css to replace the existing file and allow the two new images to
   be added inside assets.
5. Commit with: Fix responsive homepage banner artwork
6. Wait for Vercel to finish the automatic deployment.
7. Refresh the live site with Ctrl+F5 on a computer or close/reopen the browser
   tab on a phone.

NO DATABASE OR ENVIRONMENT CHANGES ARE REQUIRED.
